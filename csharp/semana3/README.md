# Semana 3 — CRUD de clientes

## Tarea

Crear una aplicación web con C# y ASP.NET Core MVC que permita registrar, listar, consultar, editar y eliminar clientes.

La tabla `Clientes` contiene `Id` y diez campos: cédula, nombres, apellidos, correo, teléfono, dirección, ciudad, provincia, fecha de nacimiento y estado activo.

## Ejecución

Desde `csharp/`, ejecutar `docker compose up -d --build` y abrir <http://127.0.0.1:8080/Clientes>.
